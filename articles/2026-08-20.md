# 📰 AI News — 2026-08-20

## 1. Binance เปิดตัวระบบ Agent OS อนุญาตให้ AI เทรดคริปโตอัตโนมัติแทนผู้ใช้

Binance เปิดตัวแพลตฟอร์ม Agent OS ที่รองรับโปรโตคอล Model Context Protocol (MCP) เพื่อเชื่อมต่อ AI อย่าง ChatGPT และ Claude Code ให้เข้าถึงข้อมูลตลาดและส่งคำสั่งซื้อขายได้ ระบบใช้กลไกบัญชีย่อยจำกัดความเสี่ยงด้านเงินทุน โดยผู้ใช้งานต้องเป็นผู้กำหนดเพดานและสิทธิ์การเข้าถึงด้วยตนเอง
สำคัญอย่างไร: เป็นก้าวสำคัญในการเปลี่ยนผ่านจาก AI แชตบอตสู่ AI Agent ที่บริหารจัดการธุรกรรมการเงินจริงและทดสอบระบบความปลอดภัยระดับบัญชี

## 2. Anthropic และ OpenAI มีมุมมองขัดแย้งต่อร่างกฎหมายควบคุมความปลอดภัย AI ในแมสซาชูเซตส์

สองแล็บ AI แถวหน้าอย่าง Anthropic และ OpenAI แสดงจุดยืนไม่ลงรอยกันต่อร่างข้อบังคับด้านความปลอดภัย AI ฉบับเข้มงวดของรัฐแมสซาชูเซตส์ ประเด็นความเห็นต่างนี้เน้นย้ำถึงการแข่งขันและกลยุทธ์ที่แตกต่างกันในการรับมือกับกฎระเบียบภาครัฐ
สำคัญอย่างไร: ส่งผลต่อทิศทางการออกกฎหมายกำกับดูแลโมเดล AI ขั้นสูงระดับมลรัฐในสหรัฐฯ และความรับผิดชอบทางกฎหมายของผู้พัฒนา

## 3. โมเดลโอเพนซอร์ส Gemma ของ Google ทำสถิติยอดดาวน์โหลดทะลุ 1 พันล้านครั้ง

Google ประกาศความสำเร็จของตระกูลโมเดลเปิด Gemma ที่มียอดดาวน์โหลดสะสมรวมเกิน 1 พันล้านครั้งทั่วโลก การเติบโตนี้สะท้อนถึงการยอมรับอย่างกว้างขวางจากนักพัฒนาและองค์กรที่นำโมเดลไปปรับแต่งใช้งานในระบบต่างๆ
สำคัญอย่างไร: ยืนยันความแข็งแกร่งของ Google ในระบบนิเวศโมเดลเปิดเพื่อแข่งกับ Llama ของ Meta โดยตรง

## 4. AWS พัฒนาระบบคุมสิทธิ์ AI Agent ป้องกันการเข้าถึงข้อมูลลับแม้อยู่ในสถานะถูกควบคุม

Amazon Web Services (AWS) นำเสนอแนวทางสถาปัตยกรรมความปลอดภัยที่จำกัดไม่ให้ AI Agent เข้าถึงข้อมูลเกินสิทธิ์ของผู้ใช้จริง มาตรการนี้ช่วยป้องกันการรั่วไหลของข้อมูลองค์กรแม้ตัวโมเดลจะถูกโจมตีแบบ Prompt Injection หรือถูกชักจูงก็ตาม
สำคัญอย่างไร: แก้จุดบกพร่องด้านความปลอดภัยที่สำคัญที่สุดของการนำ AI Agent ไปใช้งานกับข้อมูลลับในระดับคลาวด์องค์กร

## 5. โรงภาพยนตร์ในสหราชอาณาจักรเริ่มแบนแว่นตาอัจฉริยะ Meta AI สกัดการละเมิดลิขสิทธิ์

กลุ่มโรงภาพยนตร์ในสหราชอาณาจักรเริ่มบังคับใช้กฎระเบียบจำกัดการสวมใส่แว่นตาอัจฉริยะ เช่น แว่นตา Meta AI ในระหว่างการชมภาพยนตร์ มาตรการดังกล่าวถูกนำมาใช้เพื่อตัดความเสี่ยงจากการลักลอบบันทึกภาพและเสียงในโรงหนัง
สำคัญอย่างไร: ชี้ให้เห็นการปะทะกันระหว่างการแพร่หลายของอุปกรณ์ AI แบบสวมใส่กับกฎหมายคุ้มครองลิขสิทธิ์และความเป็นส่วนตัวในพื้นที่สาธารณะ
