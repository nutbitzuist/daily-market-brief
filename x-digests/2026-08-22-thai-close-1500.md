🐦 X Investment Update — รอบ 15:00 — 22 สิงหาคม 2569

🛢️ อิหร่านเปิดทางเรือน้ำมันอิรักผ่าน Hormuz หลายลำหลังกรุงแบกแดดขอ
สื่อทางการอิหร่าน (Irna) รายงานว่าอิหร่านอนุญาตให้เรือบรรทุกน้ำมันของอิรักหลายลำผ่านช่องแคบ Hormuz หลังทางการอิรักร้องขอ. ข่าวนี้ลดแรงกดดันชั่วคราวต่อเส้นทางส่งออกน้ำมันในอ่าวเปอร์เซีย แต่ยังไม่ใช่การเปิดทางถาวรของทั้งช่องแคบ. ราคาพลังงานและหุ้นพลังงานเอเชียต้นสัปดาห์จะตอบสนองเร็วถ้ามียืนยันจำนวนลำ ปริมาณบาร์เรล และระยะเวลาที่อนุญาตจริง

💾 Elon ชี้ memory supply โต ~20% ต่อปี ขณะที่ demand โต ~200% จาก data center และ Physical AI
ในช่วง SpaceX earnings call มีการอ้างคำพูดของ Elon Musk ว่ากำลังผลิต memory เพิ่มราว 20% ต่อปี แต่ความต้องการอาจพุ่งราว 200% ต่อปีหรือสูงกว่า จากทั้ง data center และ Physical AI. ถ้ากรอบนี้ใกล้ความจริง กลุ่ม DRAM/HBM อย่าง Micron และ SK Hynix ยังอยู่ในธีมอุปทานตึงตัว ก่อนสัปดาห์ที่ตลาดรอ NVDA earnings. จุดยืนยันคือตัวเลข guidance ฝั่ง memory vendors และ comment เรื่อง supply จาก hyperscaler รายอื่น
