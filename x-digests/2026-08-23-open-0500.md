🧾 ทรัมป์เปิดเผยซื้อขายหุ้นกว่า 1,000 รายการในเดือนมิถุนายน รวมมูลค่าสูงสุดราว $263M
เอกสารการเงินระบุว่าทรัมป์มีธุรกรรมหลักทรัพย์เกิน 1,000 รายการในเดือนมิ.ย. 2026 มูลค่ารวมช่วงประมาณ $78M–$263M โดยมีทั้งซื้อ Visa, Berkshire, Mastercard, Cintas และขาย ETF ขนาดใหญ่ของ Vanguard. ฝ่ายทำเนียบขาวระบุว่าการซื้อขายจัดการอิสระ แต่ตลาดยังอ่านเรื่อง conflict of interest และความเสี่ยง reputation ของสินทรัพย์ที่ชื่อประธานาธิบดีผูกอยู่. จุดยืนหุ้น financials/consumer ที่มีชื่อในรายการ และ sentiment ต่อนโยบายตลาดทุนอเมริกา อาจขยับถ้าสื่อใหญ่ขยายประเด็นนี้ต่อ

💾 ราคา AI server ของ Nvidia อาจขึ้นเกิน 15% จากต้นทุน memory พุ่ง
รายงานในตลาดระบุว่าราคา AI server ของ Nvidia มีแนวโน้มปรับขึ้นเกิน 15% เพราะต้นทุน memory เร่งตัว โดยกระทบแพลตฟอร์ม Vera Rubin และ Grace Blackwell ที่จะเริ่มส่งช่วงต้นปีหน้า. ถ้าต้นทุน memory ส่งผ่านไปยังราคาเซิร์ฟเวอร์จริง capex ของ hyperscaler ต่อ rack จะแพงขึ้น และอาจกด margin หรือเลื่อนจังหวะสั่งซื้อในห่วงโซ่ AI. รอดูว่าผู้ให้บริการคลาวด์ยืนยันการขึ้นราคา/ปรับสัญญาหรือไม่ และราคา HBM/DRAM ยังตึงต่อเนื่องแค่ไหน

🇨🇦 แคนาดาเตรียมภาษีตอบโต้อเมริกา 8 ก.ย. กระทบยานยนต์ ยกเว้นน้ำมันและก๊าซ
มีรายงานว่ามาตรการภาษีตอบโต้ของแคนาดาที่บังคับใช้ 8 ก.ย. จะไม่รวมน้ำมันและก๊าซ แต่ภาคยานยนต์จะโดนหนัก รวมถึงโรงงานในห่วงโซ่ $F และ $GM. ฝั่ง supply chain ยานยนต์อเมริกา–แคนาดาอาจเจอต้นทุนข้ามพรมแดนสูงขึ้น ขณะที่พลังงานยังถูกกันไว้เพื่อลดแรงกระแทกมหภาค. ราคาหุ้นยานยนต์และซัพพลายเออร์อเมริกาเหนือ อาจผันผวนก่อนวันมีผล รอดูรายชื่อสินค้าสุดท้ายและท่าทีตอบกลับจากวอชิงตัน
